# Independent Witness v0.1

External observer-only substrate for Reality capability-transition experiments. The first run validates the witness mechanics using deterministic fixtures A-E; it is not a certification of a real Reality capability transition.

Cases: A valid -> ACCEPT; B missing read-back -> INCOMPLETE; C contradiction -> CONTRADICTORY; D false proposal -> REJECT; E selection/completeness attack -> INCOMPLETE.

The workflow produces a witness artifact and explicitly reports independence as NOT_YET_ESTABLISHED until administrative/mutation isolation is separately demonstrated.
